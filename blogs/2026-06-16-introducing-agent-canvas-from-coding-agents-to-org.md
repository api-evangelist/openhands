Agent Canvas is OpenHands' workspace for creating automations that integrate with Slack, GitHub, and the tools where engineering work happens. It lets developers build self-hostable automations for AI coding agents across local, VM, cloud, and enterprise backends, moving beyond manual prompting to scheduled, event-driven workflows that respond automatically to engineering events.
